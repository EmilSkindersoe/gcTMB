gcTMB

2026-11-12

The package gcTMB fits growth curves over time using the Template Model Builder (TMB) framework. The curves can depend on covariates, have random effects (e.g. for repeated measurements of the same individuals), and the response can follow a range of distributions.

Growth models

All models are of the form \(f(t) = b_1 F\left(\frac{t - b_2}{b_3}\right)\), with a function \(F\) increasing from 0 to 1 that has its largest slope at 0:

  • \(b_1\) is the asymptote, the response approached at late times,
  • \(b_2\) is the time of the maximum growth rate, the inflection point of the curve,
  • \(b_3\) is the scale of the curve on the time axis, positive for an increasing curve.

The parameters \(b_4\) and \(b_5\) are reserved for future models; they are not used and always fixed.

logistic

\[ f(t) = \frac{b_1}{1 + \exp\left(-\frac{t - b_2}{b_3}\right)} \]

The curve is symmetric around \(b_2\), where it reaches half of its asymptote. The maximum growth rate is \(b_1 / (4 b_3)\).

gompertz

\[ f(t) = b_1 \exp\left(-\exp\left(-\frac{t - b_2}{b_3}\right)\right) \]

The curve reaches \(e^{-1} \approx 37\%\) of its asymptote at \(b_2\), and approaches the asymptote more slowly than it leaves zero. The maximum growth rate is \(b_1 / (e\, b_3)\).

Fitting a growth curve

The main function is gcTMB(), with the response and the time in the formula, and the growth model in model.

fit <- gcTMB(height ~ DAS, data = FabaHeights25, model = "logistic")
summary(fit)

Starting values are found from the data by a linearisation of the curve: for a given asymptote \(b_1\), \(F^{-1}(y / b_1) = (t - b_2)/b_3\) is linear in time, so a linear regression of the transformed mean responses on time gives \(b_2\) and \(b_3\). The asymptote is profiled, as the observations often do not reach it yet. gcTMBstart() shows the starting values; the start argument provides starting values for some or all of the parameters, and the fix argument fixes parameters at these values.

gcTMBstart(height ~ DAS, data = FabaHeights25, model = "logistic")
#> b1:(Intercept) b2:(Intercept) b3:(Intercept) b4:(Intercept) b5:(Intercept) 
#>      118.82055       33.02562       11.24957        0.00000        0.00000

The model is fitted by maximum likelihood. For gaussian (and lognormal) models without random effects, the inference follows nls() by default: the residual standard deviation is the square root of the unbiased residual variance with n - p residual degrees of freedom, and confidence and prediction intervals use t quantiles.

Model comparison

The logistic and Gompertz models are not nested, but can be compared by their AIC.

fitg <- gcTMB(height ~ DAS, data = FabaHeights25, model = "gompertz")
AIC(fit, fitg)
#>      df      AIC
#> fit   4 1408.214
#> fitg  4 1407.311

Predictions

With interval = "confidence", predict() adds standard errors and confidence intervals for the mean response by the delta method; with interval = "prediction", the intervals are for a new observation.

nd <- data.frame(DAS = seq(0, 80, length.out = 100))
ci <- predict(fit, newdata = nd, interval = "confidence")
pi <- predict(fit, newdata = nd, interval = "prediction")
ggplot(FabaHeights25, aes(x = DAS, y = height)) +
  geom_ribbon(data = cbind(nd, pi), aes(x = DAS, ymin = lwr, ymax = upr), inherit.aes = FALSE, fill = "blue", alpha = 0.1) +
  geom_ribbon(data = cbind(nd, ci), aes(x = DAS, ymin = lwr, ymax = upr), inherit.aes = FALSE, fill = "blue", alpha = 0.25) +
  geom_line(data = cbind(nd, ci), aes(x = DAS, y = fit), colour = "blue") +
  geom_point() +
  labs(x = "Days after sowing", y = "Height") +
  theme_minimal()

Bootstrap confidence intervals

The delta method relies on the curve being close to linear in its parameters near the estimates. A parametric bootstrap avoids this: bootstrap() simulates new responses from the fitted model and fits the model again to each of them. Passed to predict() by the boot argument, the confidence intervals are the percentile intervals of the bootstrap curves, and se.fit is their standard deviation. The same bootstrap sample can be reused for the confidence intervals of the coefficients and of timeto(), without fitting the models again.

bt <- bootstrap(fit, nsim = 500, seed = 1, progress = FALSE)
cib <- predict(fit, newdata = nd, interval = "confidence", boot = bt)
# delta method: shaded; bootstrap: dashed limits
ggplot(FabaHeights25, aes(x = DAS, y = height)) +
  geom_ribbon(data = cbind(nd, ci), aes(x = DAS, ymin = lwr, ymax = upr), inherit.aes = FALSE, fill = "blue", alpha = 0.25) +
  geom_line(data = cbind(nd, cib), aes(x = DAS, y = lwr), linetype = "dashed", colour = "red") +
  geom_line(data = cbind(nd, cib), aes(x = DAS, y = upr), linetype = "dashed", colour = "red") +
  geom_line(data = cbind(nd, ci), aes(x = DAS, y = fit), colour = "blue") +
  geom_point() +
  labs(x = "Days after sowing", y = "Height") +
  theme_minimal()

The two intervals nearly coincide here, as the curve is well determined by 200 observations. Their widths show the differences, which are largest beyond the observed days, where the curve depends on the extrapolated asymptote:

widths <- rbind(data.frame(nd, width = ci$upr - ci$lwr, method = "delta method"),
                data.frame(nd, width = cib$upr - cib$lwr, method = "bootstrap"))
ggplot(widths, aes(x = DAS, y = width, linetype = method)) +
  geom_line() +
  labs(x = "Days after sowing", y = "Width of the 95% interval", linetype = NULL) +
  theme_minimal()

Scale or rate

With the inverse link for \(b_3\), link = c(b3 = "inverse"), the coefficient of \(b_3\) is the rate \(1/b_3\). Without covariates and random effects on \(b_3\) the fit is the same; with them, covariates and random effects act additively on the rate instead of the scale.

fitr <- gcTMB(height ~ DAS, data = FabaHeights25, link = c(b3 = "inverse"))
coef(fitr)
#> b1:(Intercept) b2:(Intercept) b3:(Intercept)      log_sigma 
#>   116.62848928    32.31782512     0.09113283     2.08159664
coef(fit)[["b3:(Intercept)"]]
#> [1] 10.97299

Time to reach a level of the asymptote

timeto() gives the times at which a curve reaches a percentage of its asymptote, \(b_2 + b_3 F^{-1}(p/100)\), with standard errors by automatic differentiation. With type = "absolute", the times at which the curve reaches given responses, here a height of 50cm.

tt <- timeto(fit, respLev = c(10, 50, 90))
tt

Covariates and random effects

Covariates on the parameters are given by fform, e.g. b1 + b2 ~ trt for effects of the treatment on the asymptote and the time of the maximum growth rate. Random effects are given by rform, e.g. b1 + b2 ~ 1 | plant_ID for correlated random effects of each plant on the asymptote and the time of the maximum growth rate, which account for the repeated measurements of the plants.

FabaHeights25$trt <- factor(FabaHeights25$Treatment)
fitre <- gcTMB(height ~ DAS, fform = b1 + b2 ~ trt, rform = b1 + b2 ~ 1 | plant_ID, data = FabaHeights25)
summary(fitre)

Non-normal responses

The family argument gives the distribution of the response: “gaussian”, “lognormal”, “poisson”, “nbinom2”, “nbinom1”, “binomial”, “betabinomial” or “beta”. The data set FabaCounts23 contains the numbers of pods of 22 faba bean plants of six genotypes, counted between 61 and 79 days after sowing. A Poisson model with an asymptote and a time of the maximum growth rate for each genotype, and a random asymptote for each plant:

fitp <- gcTMB(pods ~ DAS, fform = b1 + b2 ~ Genotype, rform = b1 ~ 1 | Tube_ID, data = FabaCounts23,
              family = "poisson")

The curves of the plants, with their predicted random asymptotes, and the population curves of the genotypes (random = FALSE), the fixed effects, with 95% confidence intervals. For Poisson models, the confidence intervals of the mean are computed on the log scale, so that they stay positive.

days <- seq(61, 79, 0.25)
# a curve for each plant
ndp <- merge(unique(FabaCounts23[, c("Tube_ID", "Genotype")]), data.frame(DAS = days))
ndp$fit <- predict(fitp, newdata = ndp)
# the population curve of each genotype
ndg <- merge(genotypes, data.frame(DAS = days))
ndg <- cbind(ndg, predict(fitp, newdata = ndg, random = FALSE, interval = "confidence"))
ggplot(FabaCounts23, aes(x = DAS, y = pods)) +
